# Visual narrative

**Thesis:** Finding a startup path at Purdue should feel like a real mission: ambitious, specific, and immediately actionable.

**Surface:** Explore. The primary action is choosing a founder stage; the directory and events support that decision.

**Reference mechanism:** SpaceX.com uses immersive imagery, concise all-caps headlines, high contrast, and clear outlined calls to action. This site borrows those broad composition principles. It does not reuse SpaceX assets, copy, logo, vehicles, or page geometry.

**Original visual system:** Three conceptual university founder settings form a sequence: night workshop (begin), dawn corridor (choose a path), and auditorium before an event (show up). The same black, white, and restrained warm-gold treatment ties them together. These are generated illustrations of imagined places, not photographs of Purdue buildings or real events.

**Chapters:** Hero → founder thesis → roadmap image → six stage actions → application shortlist → source-backed directory → event image → live event list → first-week action.

**Responsive behavior:** On mobile, image focal points shift right, headlines remain left aligned, and buttons stack as needed. Content and links remain visible without JavaScript. Motion is limited to the CTA text transition and disabled for reduced-motion users.
