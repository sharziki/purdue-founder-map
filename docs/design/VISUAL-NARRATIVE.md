# Visual narrative · Purdue Founder Map

The user arrives with an unclear next step. The first screen names the product and gives one action. Three short choices route them to the guide, a person, or an opportunity; a compact club shelf shows real campus organizations. Six single-line roadmap rows make the journey legible without a wall of prose. A few application examples show how stage changes the right door. The people bridge shows actual sourced public contacts. The index provides depth on demand; it starts with eight results and expands as needed. Events make the next in-person move concrete.

The visual constant is warm paper, dark ink, and a restrained Purdue gold. The conceptual workshop image is contained and labeled; the route and directory use typography and source data rather than decorative imagery. On mobile the image follows the headline, decisions stack, and the roadmap becomes one-line chapter choices. No text is hidden before JavaScript loads. Motion is a light acknowledgement of movement through sections, not the purpose of the page.

The guide puts one visible next move above native expandable details in each chapter. The alumni route pairs four first-party portraits with an Indiana-to-San-Francisco line to explain geographic reach. It distinguishes professional location from residence and links to each public source. It does not imply a private alumni contact database or guaranteed introductions.
