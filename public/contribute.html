What makes the cut?

Each listing should help a Purdue founder take a concrete next step. We use official organization pages when possible, state who can use the opportunity, and link back to the source. Public work contact details are included only when the organization publishes them.

No private directories, scraped personal emails, unverifiable deadlines, or claimed affiliations.

Prefer a pull request?

  1. Edit resources.json, an opportunities source file, or people.json.
  2. Run the matching builder: build_data.py or build_opportunities.py, then build_catalog.py. Include generated exports.
  3. Open a pull request with your source link and what changed.
